# Calcular Total de Compra en Java

Este proyecto es un programa sencillo en Java que simula el cálculo del total de una compra en una tienda.

## Descripción
El programa solicita al usuario:
- El precio del producto
- La cantidad de unidades que desea comprar

Luego utiliza un método llamado **calcularTotal** para multiplicar el precio por la cantidad y mostrar el resultado en pantalla.

## Funcionamiento del método

Método:
calcularTotal(precio, cantidad)

Operación:
total = precio * cantidad

Retorna:
El total de la compra.

## Ejemplo de ejecución

Ingrese el precio del producto: 10  
Ingrese la cantidad de unidades: 3  

El total de la compra es: $30.00

## Lenguaje utilizado
Java
